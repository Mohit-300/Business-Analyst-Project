# Business Analyst Project

## Objective
Analyze business data to identify trends, KPIs, and insights for decision-making.

## Tools Used
- Excel (Data Cleaning, Pivot Tables, Dashboards)
- SQL (Analysis & Queries)
- Power BI (Dashboard & Visualization) 

## Work Done
- Cleaned raw data and handled missing values
- Wrote SQL queries for KPIs and insights
- Built interactive Power BI dashboard

## Outcome
Delivered actionable insights to support business decisions.
